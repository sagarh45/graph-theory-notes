Unit V · Part 1

Graph Basics

What a graph is, why almost every network in the real world is a graph, and the one counting rule you will use in every answer.

Syllabus: Definition of graph, directed and undirected graphs, basic properties.

1.1What is a graph?

Definition (write this in the exam)

A graph G is a pair of two finite sets, G = (V, E), where V is a non-empty set of vertices (also called nodes) and E is a set of edges. Each edge is a pair of vertices (u, v) and shows that u and v are connected.

In simple words

A graph is dots joined by lines. The dots are vertices, the lines are edges. That is all. A city map (cities and roads), Instagram (people and follows) and the internet (computers and cables) are all graphs.

V = { A, B, C, D, E, F }

E = { (A,B), (A,C), (B,C), (B,D),
     (C,E), (D,E), (D,F), (E,F) }

|V| = 6 is the order of the graph. |E| = 8 is the size of the graph.

A graph is a non-linear data structure: one vertex can be connected to many others, in any pattern. There is no first or last element and no root.

Graph = vertices + edges. Nothing else matters — not the position of the dots, not the length or shape of the lines.

The same graph can be drawn in many ways. If you move vertex F to the top of the page, it is still the same graph, because the same pairs are connected. Only the connections matter.

1.2Graphs around you

Whenever things are connected to other things, you have a graph. Learning graphs means learning how Google Maps, social media and the internet work underneath.

Road map

Cities are vertices, roads are edges. The road length is the weight. Google Maps runs a shortest-path algorithm (Part 6).

Friends network

People are vertices; a friendship is an edge. Friendship goes both ways, so the graph is undirected.

Instagram follows

If you follow someone, they may not follow you back. Each follow is an arrow, so this graph is directed.

Course prerequisites

“C before Data Structures before Algorithms.” Arrows with no loop: a DAG. Topological sort gives a valid study order.

Computer network

Routers are vertices and cables are edges. Routing protocols such as OSPF use Dijkstra to send packets on the fastest path.

Web pages

Each page is a vertex and each hyperlink is a directed edge. Search engines walk this graph with BFS to discover pages.

1.4Degree and the handshake rule

The degree of a vertex is the number of edges touching it. In Figure 1, deg(A) = 2 and deg(B) = 3.

Handshake lemma: in every undirected graph, the sum of all degrees = 2 × (number of edges).
Σ deg(v) = 2|E|

Why it is true: every edge has two ends. When you add up the degrees, each edge is counted once at each end, so it is counted exactly twice. In Figure 1: 2 + 3 + 3 + 3 + 3 + 2 = 16 = 2 × 8.

Result you get for free: the number of vertices with an odd degree is always even. The total 2|E| is even; the even degrees add up to an even number, so the odd degrees must also add up to an even number, and that needs an even count of them.

Exam use: “Can a graph have 5 vertices with degrees 3, 3, 3, 3, 3?” No. The sum is 15, which is odd, but the sum of degrees must be 2|E| (even). Equally: it would have 5 odd-degree vertices, which is an odd count.

For a directed graph the rule becomes: Σ in-degree = Σ out-degree = |E|. Each arrow leaves one vertex and enters one vertex.

1.5How many edges can a graph have?

In a simple graph (no loops, no repeated edges) every pair of vertices can have at most one edge. With n vertices there are n(n − 1)/2 pairs.

A graph with close to the maximum number of edges is dense. A graph with few edges (about n) is sparse. Most real graphs, like road maps, are sparse. This decides which representation to use in Part 4.

Graph Terminology

The words every graph question uses. Each term comes with a picture and a one-line meaning you can write in the exam.

Syllabus: Graph terminology — adjacent vertices and edges, degree, in-degree, out-degree, path, cycle, loop, multiple edges, connected graph.

2.1Adjacent, incident, neighbour

Adjacent vertices: two vertices joined by an edge. A and B are adjacent. A and D are not.

Neighbours of v: all vertices adjacent to v. Neighbours of B = {A, C, D}.

Incident edge: an edge is incident on the two vertices at its ends. Edge (B, D) is incident on B and on D.

Adjacent edges: two edges that share a common vertex. (A, B) and (B, D) are adjacent because both touch B.

2.4Loops and multiple edges

Self-loop: an edge that starts and ends at the same vertex, like (C, C). In an undirected graph a loop adds 2 to the degree, so deg(C) = 4 here.

Multiple (parallel) edges: two or more edges between the same pair of vertices, like the two A–B edges.

A graph with no loops and no multiple edges is called simple. Most algorithms in this unit assume a simple graph.

Unit V · Part 3

Types of Graph

Graphs get a name from one rule they follow. Learn the rule and the picture together — the exam asks for both.

Syllabus: Types of graph — simple, multigraph, directed, undirected, weighted, regular, complete, strongly and weakly connected, isomorphic graphs.

3.1Null, simple, multigraph, pseudograph

Null graph (edgeless / empty graph)

Vertices but no edges. Every vertex is isolated. A null graph with one vertex is the trivial graph.

|E| = 0

Simple graph

At most one edge between any two vertices and no self-loops. This is the default meaning of “graph” in most questions.

no loops · no parallel edges

Multigraph

Allows multiple (parallel) edges between the same pair, but no loops. Example: two different train routes between the same two cities.

parallel edges allowed

Pseudograph

Allows both parallel edges and self-loops. The most general undirected graph.

loops + parallel edges allowed

3.2Directed, undirected, weighted

Undirected graph

Edges have no direction. (u, v) = (v, u). Movement is allowed both ways.

Directed graph (digraph)

Every edge has a direction, drawn as an arrow. <u, v> ≠ <v, u>.

Weighted graph (network)

Each edge carries a number called its weight or cost — distance, time, price, bandwidth. Weighted graphs are the input for MST and shortest-path algorithms (Part 6). A weighted graph can be directed or undirected.

3.3Regular and complete graphs

Regular graph (k-regular)

Every vertex has the same degree k. A cycle is 2-regular. By the handshake rule a k-regular graph on n vertices has nk/2 edges.

deg(v) = k for every v

Complete graph (Kn)

Every vertex is joined to every other vertex by exactly one edge. Kn has n(n − 1)/2 edges and is (n − 1)-regular. Every complete graph is regular, but not every regular graph is complete.

|E| = n(n − 1)/2

3.4Bipartite graphs

Bipartite graph

The vertices can be split into two groups so that every edge goes from one group to the other. No edge stays inside a group. Example: students on one side, courses on the other; an edge means “is enrolled in”.

Test: a graph is bipartite if and only if it has no odd-length cycle. BFS can check this by colouring levels alternately.

Complete bipartite (Km,n)

Every vertex of the first group (size m) is joined to every vertex of the second group (size n). It has m × n edges. Shown: K2,3 with 6 edges.

3.5Connected, strongly and weakly connected

Connected graph

An undirected graph in which there is a path between every pair of vertices.

Disconnected graph

At least two vertices have no path between them. Here {A, B, C} and {D, E} are the two components.

Strongly connected

A directed graph in which you can go from every vertex to every other vertex following the arrows. Here A → B → C → D → A works from any start.

✓ every u → v and v → u

Weakly connected

Not strongly connected, but it becomes connected if you ignore the arrow directions. Here nothing leaves B, so B cannot reach anyone — but as an undirected graph it is one piece.

not strongly connected
Strongly connected ⇒ weakly connected. The reverse is not true.

3.6Cyclic, acyclic, DAG, tree, forest

Cyclic graph

Contains at least one cycle (here A–B–C–A).

DAG (directed acyclic graph)

A directed graph with no directed cycle. Used for task scheduling, course plans, build systems (which file to compile first) and spreadsheets (which cell to compute first). Every DAG has a topological order (Part 6).

Tree

A connected, acyclic undirected graph. It always has n − 1 edges and exactly one path between any two vertices.

Forest

An acyclic graph that may be disconnected — a set of trees. A forest with n vertices and c trees has n − c edges.

3.7Isomorphic and planar graphs

Two graphs are isomorphic if you can rename the vertices of one to get exactly the other — same structure, different drawing. Here the mapping 1→Q, 2→P, 3→S, 4→R turns every edge of G₁ into an edge of G₂.

Exam check-list: isomorphic graphs must have the same (1) number of vertices, (2) number of edges, (3) degree sequence. G₁: degrees 3, 2, 3, 2. G₂: degrees 2, 3, 2, 3 → sorted both are 3, 3, 2, 2 ✓. These checks are necessary but not enough; to prove isomorphism you must give the mapping.

A planar graph can be drawn on paper with no two edges crossing. Circuit boards must be planar (or use more layers). K₅ and K3,3 are the classic non-planar graphs.

Unit V · Part 4

Representation of Graphs

A computer cannot see a drawing. We must store “who is connected to whom” as numbers. There are four standard ways; two of them are used almost everywhere.

Syllabus: Representation of graphs — adjacency matrix, adjacency list, incidence matrix; their programs and comparison.

4.1Adjacency matrix

Definition

For a graph with n vertices, the adjacency matrix A is an n × n array where A[i][j] = 1 if there is an edge from vertex i to vertex j, and A[i][j] = 0 otherwise.

In simple words

Make a table with one row and one column for every vertex. Put a 1 in the box where row u meets column v if u and v are connected.

Properties

  • Space: always n² cells, even if the graph has very few edges.
  • Check “is there an edge u–v?” in O(1) — just read A[u][v].
  • Find all neighbours of u: scan the whole row, O(n).
  • Undirected ⇒ symmetric (A[u][v] = A[v][u]). Only the upper half needs to be stored.
  • Diagonal is all 0 in a simple graph (no self-loops).
  • Number of 1s = 2|E| (undirected) or |E| (directed).
Program 1 — adjacency matrix: create, display, degrees
/* Adjacency matrix: create, display, degree of every vertex */
#include <stdio.h>
#define MAX 20

int adj[MAX][MAX];
int n, directed;

void createGraph() {
    int e, i;
    char u, v;
    printf("Number of vertices: ");
    scanf("%d", &n);
    printf("Directed? (1 = yes, 0 = no): ");
    scanf("%d", &directed);
    printf("Number of edges: ");
    scanf("%d", &e);
    for (i = 0; i < e; i++) {
        printf("Edge %d (e.g. A B): ", i + 1);
        scanf(" %c %c", &u, &v);
        adj[u - 'A'][v - 'A'] = 1;
        if (!directed)
            adj[v - 'A'][u - 'A'] = 1;   /* undirected: both ways */
    }
}

void displayMatrix() {
    int i, j;
    printf("\nAdjacency matrix:\n   ");
    for (j = 0; j < n; j++) printf(" %c", 'A' + j);
    printf("\n");
    for (i = 0; i < n; i++) {
        printf(" %c ", 'A' + i);
        for (j = 0; j < n; j++) printf(" %d", adj[i][j]);
        printf("\n");
    }
}

void degrees() {
    int i, j, in, out;
    printf("\nVertex  ");
    printf(directed ? "In  Out\n" : "Degree\n");
    for (i = 0; i < n; i++) {
        in = out = 0;
        for (j = 0; j < n; j++) {
            out += adj[i][j];            /* row sum    */
            in  += adj[j][i];            /* column sum */
        }
        if (directed) printf("  %c     %d   %d\n", 'A' + i, in, out);
        else          printf("  %c     %d\n", 'A' + i, out);
    }
}

int main() {
    createGraph();
    displayMatrix();
    degrees();
    return 0;
}

4.2Adjacency list

Definition

An adjacency list keeps an array of n head pointers, one per vertex. Head[u] points to a linked list of all vertices adjacent to u.

In simple words

For every vertex, write down the list of its neighbours. Like a phone's contact list: each person has their own list of friends.

struct node {
    int vertex;          /* neighbour number          */
    int weight;          /* only for weighted graphs  */
    struct node *next;   /* next neighbour in list    */
};
struct node *head[MAX];  /* head[u] = first neighbour of u */

Properties

  • Space: O(n + e) — n heads plus 2e nodes (undirected) or e nodes (directed).
  • List all neighbours of u in O(deg(u)) — only real neighbours are visited. This makes BFS and DFS fast.
  • Check “is there an edge u–v?” needs a scan of u's list: O(deg(u)).
  • In-degree in a digraph is slow: you must scan every list (or keep an inverse list).
Program 2 — adjacency list with linked lists
/* Adjacency list using linked lists (new node added at the end) */
#include <stdio.h>
#include <stdlib.h>
#define MAX 20

struct node {
    int vertex;
    struct node *next;
};

struct node *head[MAX];
int n;

void addEdge(int u, int v) {
    struct node *p, *nn = (struct node *)malloc(sizeof(struct node));
    nn->vertex = v;
    nn->next = NULL;
    if (head[u] == NULL) {
        head[u] = nn;
        return;
    }
    p = head[u];
    while (p->next != NULL) p = p->next;
    p->next = nn;
}

void display() {
    int i;
    struct node *p;
    printf("\nAdjacency list:\n");
    for (i = 0; i < n; i++) {
        printf(" %c", 'A' + i);
        for (p = head[i]; p != NULL; p = p->next)
            printf(" -> %c", 'A' + p->vertex);
        printf(" -> NULL\n");
    }
}

int main() {
    int e, i, directed;
    char u, v;
    printf("Number of vertices: ");
    scanf("%d", &n);
    printf("Directed? (1 = yes, 0 = no): ");
    scanf("%d", &directed);
    printf("Number of edges: ");
    scanf("%d", &e);
    for (i = 0; i < e; i++) {
        printf("Edge %d (e.g. A B): ", i + 1);
        scanf(" %c %c", &u, &v);
        addEdge(u - 'A', v - 'A');
        if (!directed) addEdge(v - 'A', u - 'A');
    }
    display();
    return 0;
}

4.3Incidence matrix

Definition

The incidence matrix is an n × e array (rows = vertices, columns = edges). M[v][k] = 1 if edge k touches vertex v, otherwise 0. For a digraph, use +1 at the start (tail) and −1 at the end (head) of the edge.

Space is n × e, which is large for most graphs, so the incidence matrix is used mainly in theory and in electrical circuit analysis (Kirchhoff's laws).

4.4Edge list

The simplest form: just store every edge as a pair (u, v), or a triple (u, v, w) for a weighted graph. Space is O(e).

Finding neighbours is slow (scan all edges), but sorting edges by weight is easy. That is exactly what Kruskal's algorithm needs, so Kruskal uses an edge list.

Unit V · Part 5

Graph Traversal: BFS and DFS

Traversal means visiting every vertex exactly once. BFS spreads out level by level using a queue. DFS goes deep first using a stack. Watch both run step by step.

Syllabus: Graph traversal — Breadth First Search and Depth First Search, algorithms, programs and comparison.

5.1Why traversal needs a visited[] array

In a tree you can never come back to a node you already saw. A graph can have cycles: from A you go to B, from B to C, and from C back to A. Without a record, the traversal would go round forever.

Keep an array visited[n], all 0 at the start. Set visited[v] = 1 the moment you first reach v, and never process v again.
BFS — Breadth First Search

Like ripples on water: visit the start, then all vertices 1 edge away, then all 2 edges away, and so on. Uses a queue.

DFS — Depth First Search

Like walking through a maze: keep going forward as deep as you can; when you hit a dead end, go back one step and try another way. Uses a stack (or recursion).

Order rule used in these notes and in most exams: when a vertex has several unvisited neighbours, take them in alphabetical (or numerical) order, which is the order in the adjacency matrix row. A different neighbour order gives a different but still correct traversal — always state your order.

5.2Breadth First Search (BFS)

BFS(G, s)
1. Set visited[v] = 0 for every vertex v.
2. visited[s] = 1;  ENQUEUE(s)
3. While the queue is not empty:
     u = DEQUEUE();  print u
     For every neighbour v of u (in order):
         If visited[v] == 0:
             visited[v] = 1;  ENQUEUE(v)
4. Stop.

Press Play or use Next. The label under each vertex is its level — the number of edges from the start. The side panel shows the queue with its front (F) and rear (R), the visited array and the output.

Dry run table (write this in the exam)

Common mistake: Marking a vertex visited only when it is dequeued. Then the same vertex can enter the queue twice (for example F from both C and E). Mark it visited when you enqueue it.

What BFS gives you for free

  • Shortest path in an unweighted graph: the level of v is the fewest edges from s to v. Follow the thick BFS-tree edges back to s to get the path.
  • BFS spanning tree: the thick edges form a tree that reaches every vertex in the component.
  • Connected components: start BFS again from any unvisited vertex; each new start is a new component.
  • Bipartite test: colour levels even/odd. If an edge joins two vertices of the same level, the graph is not bipartite.

5.3Depth First Search (DFS)

Recursive

DFS(u)
1. visited[u] = 1;  print u
2. For every neighbour v of u (in order):
       If visited[v] == 0:
           DFS(v)
3. Return.

With an explicit stack

DFS_STACK(s)
1. PUSH(s)
2. While the stack is not empty:
     u = POP()
     If visited[u] == 1: continue
     visited[u] = 1;  print u
     Push unvisited neighbours of u
       in REVERSE order (so the smallest
       is on top and comes out first)

Program 3 — BFS using a queue
/* Breadth First Search on an adjacency matrix */
#include <stdio.h>
#define MAX 20

int adj[MAX][MAX], visited[MAX];
int queue[MAX], front = 0, rear = -1;
int n;

void enqueue(int v) { queue[++rear] = v; }
int  dequeue()      { return queue[front++]; }
int  isEmpty()      { return front > rear; }

void bfs(int start) {
    int u, v;
    visited[start] = 1;
    enqueue(start);
    while (!isEmpty()) {
        u = dequeue();
        printf("%c ", 'A' + u);
        for (v = 0; v < n; v++) {          /* neighbours in order A, B, C ... */
            if (adj[u][v] == 1 && !visited[v]) {
                visited[v] = 1;            /* mark when enqueued, not when printed */
                enqueue(v);
            }
        }
    }
}

int main() {
    int e, i;
    char u, v, s;
    printf("Number of vertices: ");
    scanf("%d", &n);
    printf("Number of edges: ");
    scanf("%d", &e);
    for (i = 0; i < e; i++) {
        printf("Edge %d: ", i + 1);
        scanf(" %c %c", &u, &v);
        adj[u - 'A'][v - 'A'] = adj[v - 'A'][u - 'A'] = 1;
    }
    printf("Start vertex: ");
    scanf(" %c", &s);
    printf("\nBFS order: ");
    bfs(s - 'A');
    printf("\n");
    return 0;
}

Program 4 — DFS, recursive and with a stack
/* Depth First Search: recursive version and explicit-stack version */
#include <stdio.h>
#define MAX 20

int adj[MAX][MAX], visited[MAX];
int n;

void dfs(int u) {                         /* recursive: uses the call stack */
    int v;
    visited[u] = 1;
    printf("%c ", 'A' + u);
    for (v = 0; v < n; v++)
        if (adj[u][v] == 1 && !visited[v])
            dfs(v);
}

void dfsStack(int start) {                /* same order with our own stack */
    int stack[MAX * MAX], top = -1, u, v;
    stack[++top] = start;
    while (top >= 0) {
        u = stack[top--];                 /* pop */
        if (visited[u]) continue;
        visited[u] = 1;
        printf("%c ", 'A' + u);
        for (v = n - 1; v >= 0; v--)      /* push in reverse so A..Z come out first */
            if (adj[u][v] == 1 && !visited[v])
                stack[++top] = v;
    }
}

int main() {
    int e, i;
    char u, v, s;
    printf("Number of vertices: ");
    scanf("%d", &n);
    printf("Number of edges: ");
    scanf("%d", &e);
    for (i = 0; i < e; i++) {
        printf("Edge %d: ", i + 1);
        scanf(" %c %c", &u, &v);
        adj[u - 'A'][v - 'A'] = adj[v - 'A'][u - 'A'] = 1;
    }
    printf("Start vertex: ");
    scanf(" %c", &s);

    printf("\nDFS (recursive): ");
    dfs(s - 'A');

    for (i = 0; i < n; i++) visited[i] = 0;
    printf("\nDFS (stack)    : ");
    dfsStack(s - 'A');
    printf("\n");
    return 0;
}

Remember from Part 5

  • BFS = queue, level by level. DFS = stack/recursion, deep first.
  • Mark visited when you enqueue (BFS) or when you first reach the vertex (DFS).
  • Both take O(V + E) with an adjacency list, O(V²) with a matrix.
  • BFS gives the fewest-edges path. A DFS back edge means a cycle.
  • Disconnected graph: restart from any unvisited vertex; count the restarts to count components.

6.1Spanning tree and minimum spanning tree

Definition

A spanning tree of a connected graph G is a subgraph that includes every vertex of G and is a tree (connected, no cycle). It always has n − 1 edges. A minimum spanning tree (MST) is a spanning tree whose total edge weight is as small as possible.

In simple words

You must lay cables to connect 7 villages. Every village must be reachable, and cable is expensive. The MST tells you which roads to lay cable along so that the total cable length is the least.

  • A connected graph with n vertices can have many spanning trees. Kn has nn−2 of them (Cayley's formula): K4 has 16.
  • Adding any one more edge to a spanning tree creates exactly one cycle. Removing any edge disconnects it.
  • If all edge weights are different, the MST is unique.
  • Both algorithms below are greedy: they always take the cheapest safe edge and never undo a choice.

6.2Prim's algorithm

Idea: grow one tree. Start from any vertex. At every step add the cheapest edge that joins a tree vertex to a non-tree vertex. It is BFS with a priority instead of a plain queue.

PRIM(G, s)
1. key[v] = ∞, parent[v] = NIL, inTree[v] = 0 for every v
2. key[s] = 0
3. Repeat n times:
     u = vertex with inTree[u] = 0 and the smallest key[u]
     inTree[u] = 1                  // add u (and edge parent[u]–u) to the MST
     For every neighbour v of u with inTree[v] = 0:
         If w(u, v) < key[v]:
             key[v] = w(u, v);  parent[v] = u

Order of edges added: A–D (5), D–F (6), A–B (7), B–E (7), E–C (5), E–G (9). Total = 39. Note that Prim can add a cheap edge (E–C, 5) late, because C was not reachable cheaply until E joined the tree.

Program 5 — Prim's MST (adjacency matrix, O(n²))
/* Prim's minimum spanning tree, O(n^2) with an adjacency matrix */
#include <stdio.h>
#include <limits.h>
#define MAX 20

int cost[MAX][MAX];     /* 0 = no edge */
int n;

void prim(int start) {
    int key[MAX], parent[MAX], inTree[MAX];
    int i, k, u, v, total = 0;
    for (i = 0; i < n; i++) {
        key[i] = INT_MAX;
        parent[i] = -1;
        inTree[i] = 0;
    }
    key[start] = 0;
    printf("\nEdge   Weight\n");
    for (k = 0; k < n; k++) {
        u = -1;                                   /* pick the smallest key */
        for (i = 0; i < n; i++)
            if (!inTree[i] && key[i] != INT_MAX && (u == -1 || key[i] < key[u]))
                u = i;
        if (u == -1) { printf("Graph is not connected\n"); return; }
        inTree[u] = 1;
        if (parent[u] != -1) {
            printf("%c - %c   %d\n", 'A' + parent[u], 'A' + u, cost[parent[u]][u]);
            total += cost[parent[u]][u];
        }
        for (v = 0; v < n; v++)                   /* update keys of neighbours */
            if (cost[u][v] && !inTree[v] && cost[u][v] < key[v]) {
                key[v] = cost[u][v];
                parent[v] = u;
            }
    }
    printf("Total weight of MST = %d\n", total);
}

int main() {
    int e, i, w;
    char u, v, s;
    printf("Number of vertices: ");
    scanf("%d", &n);
    printf("Number of edges: ");
    scanf("%d", &e);
    for (i = 0; i < e; i++) {
        printf("Edge %d (u v weight): ", i + 1);
        scanf(" %c %c %d", &u, &v, &w);
        cost[u - 'A'][v - 'A'] = cost[v - 'A'][u - 'A'] = w;
    }
    printf("Start vertex: ");
    scanf(" %c", &s);
    prim(s - 'A');
    return 0;
}

6.3Kruskal's algorithm

Idea: forget about growing one tree. Sort all edges from cheapest to costliest and take them one by one. Skip an edge if its two ends are already connected (it would make a cycle). Stop at n − 1 edges.

KRUSKAL(G)
1. Sort all edges by weight (smallest first)
2. Make a separate set for every vertex: {A} {B} {C} ...
3. For each edge (u, v) in sorted order:
     If FIND(u) ≠ FIND(v):          // different sets → no cycle
         add (u, v) to the MST
         UNION(u, v)
     Else: reject (cycle)
4. Stop when the MST has n − 1 edges.

The same graph gives the same total, 39, but the edges are picked in a different order: A–D, C–E, D–F, A–B, B–E, (reject B–C, E–F, B–D), E–G.

Program 6 — Kruskal's MST with union-find
/* Kruskal's minimum spanning tree with union-find */
#include <stdio.h>
#define MAX 50

struct edge { int u, v, w; };

struct edge E[MAX];
int parent[MAX];
int n, e;

int find(int x) {                         /* root of x's set (with path compression) */
    if (parent[x] != x)
        parent[x] = find(parent[x]);
    return parent[x];
}

void sortEdges() {                        /* simple bubble sort by weight */
    int i, j;
    struct edge t;
    for (i = 0; i < e - 1; i++)
        for (j = 0; j < e - 1 - i; j++)
            if (E[j].w > E[j + 1].w) { t = E[j]; E[j] = E[j + 1]; E[j + 1] = t; }
}

int main() {
    int i, taken = 0, total = 0, ru, rv;
    char a, b;
    printf("Number of vertices: ");
    scanf("%d", &n);
    printf("Number of edges: ");
    scanf("%d", &e);
    for (i = 0; i < e; i++) {
        printf("Edge %d (u v weight): ", i + 1);
        scanf(" %c %c %d", &a, &b, &E[i].w);
        E[i].u = a - 'A';
        E[i].v = b - 'A';
    }
    for (i = 0; i < n; i++) parent[i] = i;  /* every vertex is its own set */
    sortEdges();

    printf("\nEdge   Weight  Result\n");
    for (i = 0; i < e && taken < n - 1; i++) {
        ru = find(E[i].u);
        rv = find(E[i].v);
        if (ru != rv) {
            parent[ru] = rv;                  /* union */
            taken++;
            total += E[i].w;
            printf("%c - %c   %2d    taken\n", 'A' + E[i].u, 'A' + E[i].v, E[i].w);
        } else {
            printf("%c - %c   %2d    rejected (cycle)\n", 'A' + E[i].u, 'A' + E[i].v, E[i].w);
        }
    }
    printf("Total weight of MST = %d\n", total);
    return 0;
}

6.4Dijkstra's shortest path

Idea: keep a tentative distance dist[v] for every vertex. Repeatedly pick the unfinished vertex with the smallest dist — its distance can no longer improve, so fix it. Then try to improve its neighbours: this is called relaxing an edge.

DIJKSTRA(G, s)
1. dist[v] = ∞, prev[v] = NIL, done[v] = 0 for every v;  dist[s] = 0
2. Repeat n times:
     u = unfinished vertex with the smallest dist[u]
     done[u] = 1
     For every neighbour v of u with done[v] = 0:      // RELAX
         If dist[u] + w(u, v) < dist[v]:
             dist[v] = dist[u] + w(u, v);  prev[v] = u
3. The path to t: follow prev[] back from t to s.

Notice: the direct edge A–B costs 4, but A → C → B costs 2 + 1 = 3. Dijkstra finds this when it relaxes C–B. The final distances are A 0, B 3, C 2, D 8, E 10, F 13.

Common mistake: Using Dijkstra with negative edge weights. Once a vertex is fixed it is never updated again, so a later negative edge cannot correct it. Use the Bellman–Ford algorithm for negative weights (it relaxes every edge n − 1 times, O(n·e)).
Program 7 — Dijkstra (adjacency matrix, O(n²))
/* Dijkstra's shortest paths, O(n^2) with an adjacency matrix */
#include <stdio.h>
#include <limits.h>
#define MAX 20

int cost[MAX][MAX];     /* 0 = no edge */
int n;

void printPath(int prev[], int v) {
    if (prev[v] != -1) {
        printPath(prev, prev[v]);
        printf(" -> ");
    }
    printf("%c", 'A' + v);
}

void dijkstra(int s) {
    int dist[MAX], prev[MAX], done[MAX];
    int i, k, u, v;
    for (i = 0; i < n; i++) {
        dist[i] = INT_MAX;
        prev[i] = -1;
        done[i] = 0;
    }
    dist[s] = 0;
    for (k = 0; k < n; k++) {
        u = -1;                                   /* unfinished vertex with smallest dist */
        for (i = 0; i < n; i++)
            if (!done[i] && dist[i] != INT_MAX && (u == -1 || dist[i] < dist[u]))
                u = i;
        if (u == -1) break;                       /* the rest are unreachable */
        done[u] = 1;
        for (v = 0; v < n; v++)                   /* relax every edge u -> v */
            if (cost[u][v] && !done[v] && dist[u] + cost[u][v] < dist[v]) {
                dist[v] = dist[u] + cost[u][v];
                prev[v] = u;
            }
    }
    printf("\nVertex  Distance  Path\n");
    for (i = 0; i < n; i++) {
        if (dist[i] == INT_MAX) { printf("  %c     unreachable\n", 'A' + i); continue; }
        printf("  %c     %4d      ", 'A' + i, dist[i]);
        printPath(prev, i);
        printf("\n");
    }
}

int main() {
    int e, i, w;
    char u, v, s;
    printf("Number of vertices: ");
    scanf("%d", &n);
    printf("Number of edges: ");
    scanf("%d", &e);
    for (i = 0; i < e; i++) {
        printf("Edge %d (u v weight): ", i + 1);
        scanf(" %c %c %d", &u, &v, &w);
        cost[u - 'A'][v - 'A'] = cost[v - 'A'][u - 'A'] = w;   /* undirected */
    }
    printf("Source vertex: ");
    scanf(" %c", &s);
    dijkstra(s - 'A');
    return 0;
}

6.5Topological sort

Definition

A topological order of a DAG is a line-up of all vertices such that for every edge u → v, u comes before v.

In simple words

You want to get dressed: socks before shoes, shirt before tie. Topological sort gives an order that respects every “before” rule. If the rules go in a circle (A before B before A), no order is possible.

Kahn's method: repeatedly take a vertex with in-degree 0 (nothing left that must come before it), write it down, and delete its outgoing edges.

TOPO_SORT(G)
1. Compute in[v] for every vertex
2. Put every vertex with in[v] = 0 into a queue
3. While the queue is not empty:
     u = DEQUEUE();  print u
     For every edge u → v:
         in[v] = in[v] − 1
         If in[v] == 0: ENQUEUE(v)
4. If fewer than n vertices were printed → the graph has a cycle.
Program 8 — Topological sort (Kahn)
/* Topological sort (Kahn's algorithm) on a directed graph */
#include <stdio.h>
#define MAX 20

int adj[MAX][MAX], indeg[MAX];
int n;

int main() {
    int e, i, v, u, queue[MAX], front = 0, rear = -1, count = 0;
    char a, b;
    printf("Number of vertices: ");
    scanf("%d", &n);
    printf("Number of edges: ");
    scanf("%d", &e);
    for (i = 0; i < e; i++) {
        printf("Edge %d (from to): ", i + 1);
        scanf(" %c %c", &a, &b);
        adj[a - 'A'][b - 'A'] = 1;
        indeg[b - 'A']++;
    }
    for (i = 0; i < n; i++)                     /* all vertices with no prerequisite */
        if (indeg[i] == 0) queue[++rear] = i;

    printf("\nTopological order: ");
    while (front <= rear) {
        u = queue[front++];
        printf("%c ", 'A' + u);
        count++;
        for (v = 0; v < n; v++)
            if (adj[u][v]) {
                indeg[v]--;                     /* remove edge u -> v */
                if (indeg[v] == 0) queue[++rear] = v;
            }
    }
    if (count < n) printf("\nThe graph has a cycle - no topological order.");
    printf("\n");
    return 0;
}

R.3Common mistakes

1. Path length is the number of edges, not vertices.
2. A self-loop adds 2 to the degree in an undirected graph.
3. In BFS mark a vertex visited when it is enqueued, or it may enter the queue twice.
4. BFS/DFS order depends on the neighbour order. State “neighbours taken in alphabetical order”.
5. For a disconnected graph, one BFS/DFS does not reach everything — restart from an unvisited vertex.
6. Weakly connected is not strongly connected. Check that arrows allow travel both ways.
7. Same vertex count, edge count and degrees do not prove two graphs are isomorphic. Give the mapping.
8. Dijkstra fails with negative weights; topological sort fails on any directed cycle.

R.4Model answers

Q1Define a graph. Differentiate between directed and undirected graphs. (5 marks)

A graph G = (V, E) is a non-linear data structure made of a finite non-empty set V of vertices and a set E of edges, where each edge connects a pair of vertices.

In an undirected graph each edge is an unordered pair (u, v) = (v, u) and can be travelled both ways; its adjacency matrix is symmetric; each vertex has one degree; maximum edges n(n − 1)/2. In a directed graph each edge is an ordered pair <u, v> from tail u to head v and can be travelled one way only; its matrix need not be symmetric; each vertex has an in-degree and an out-degree; maximum edges n(n − 1). Draw one small example of each.

Q2Explain the following terms with an example: degree, path, cycle, loop, multiple edges, connected graph.

Use Figure 1 of Part 1. Degree = edges at a vertex, deg(B) = 3. Path = sequence of adjacent vertices without repetition, A–B–D–F. Cycle = path returning to its start, B–C–E–D–B. Loop = edge (v, v). Multiple edges = two or more edges between the same pair. Connected graph = a path exists between every pair of vertices.

Q3Prove that the number of odd-degree vertices in any graph is even.

By the handshake lemma Σ deg(v) = 2e, which is even. Split the sum into even-degree vertices and odd-degree vertices. The even part is even, so the odd part = 2e − (even) is also even. A sum of odd numbers is even only when there is an even count of them. Hence the number of odd-degree vertices is even. ∎

Choose from Part 3: simple, multigraph, weighted, regular, complete, bipartite, strongly/weakly connected, DAG, isomorphic. For each: one-line rule + small diagram + one property (e.g. Kn has n(n − 1)/2 edges).
