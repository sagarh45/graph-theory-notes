Unit V · Part 4

Representation of Graphs

A computer cannot see a drawing. We must store “who is connected to whom” as numbers. There are four standard ways; two of them are used almost everywhere.

Syllabus: Representation of graphs — adjacency matrix, adjacency list, incidence matrix; their programs and comparison.

4.1Adjacency matrix

Definition

For a graph with n vertices, the adjacency matrix A is an n × n array where A[i][j] = 1 if there is an edge from vertex i to vertex j, and A[i][j] = 0 otherwise.

In simple words

Make a table with one row and one column for every vertex. Put a 1 in the box where row u meets column v if u and v are connected.

Properties

  • Space: always n² cells, even if the graph has very few edges.
  • Check “is there an edge u–v?” in O(1) — just read A[u][v].
  • Find all neighbours of u: scan the whole row, O(n).
  • Undirected ⇒ symmetric (A[u][v] = A[v][u]). Only the upper half needs to be stored.
  • Diagonal is all 0 in a simple graph (no self-loops).
  • Number of 1s = 2|E| (undirected) or |E| (directed).
Program 1 — adjacency matrix: create, display, degrees
/* Adjacency matrix: create, display, degree of every vertex */
#include <stdio.h>
#define MAX 20

int adj[MAX][MAX];
int n, directed;

void createGraph() {
    int e, i;
    char u, v;
    printf("Number of vertices: ");
    scanf("%d", &n);
    printf("Directed? (1 = yes, 0 = no): ");
    scanf("%d", &directed);
    printf("Number of edges: ");
    scanf("%d", &e);
    for (i = 0; i < e; i++) {
        printf("Edge %d (e.g. A B): ", i + 1);
        scanf(" %c %c", &u, &v);
        adj[u - 'A'][v - 'A'] = 1;
        if (!directed)
            adj[v - 'A'][u - 'A'] = 1;   /* undirected: both ways */
    }
}

void displayMatrix() {
    int i, j;
    printf("\nAdjacency matrix:\n   ");
    for (j = 0; j < n; j++) printf(" %c", 'A' + j);
    printf("\n");
    for (i = 0; i < n; i++) {
        printf(" %c ", 'A' + i);
        for (j = 0; j < n; j++) printf(" %d", adj[i][j]);
        printf("\n");
    }
}

void degrees() {
    int i, j, in, out;
    printf("\nVertex  ");
    printf(directed ? "In  Out\n" : "Degree\n");
    for (i = 0; i < n; i++) {
        in = out = 0;
        for (j = 0; j < n; j++) {
            out += adj[i][j];            /* row sum    */
            in  += adj[j][i];            /* column sum */
        }
        if (directed) printf("  %c     %d   %d\n", 'A' + i, in, out);
        else          printf("  %c     %d\n", 'A' + i, out);
    }
}

int main() {
    createGraph();
    displayMatrix();
    degrees();
    return 0;
}

4.2Adjacency list

Definition

An adjacency list keeps an array of n head pointers, one per vertex. Head[u] points to a linked list of all vertices adjacent to u.

In simple words

For every vertex, write down the list of its neighbours. Like a phone's contact list: each person has their own list of friends.

struct node {
    int vertex;          /* neighbour number          */
    int weight;          /* only for weighted graphs  */
    struct node *next;   /* next neighbour in list    */
};
struct node *head[MAX];  /* head[u] = first neighbour of u */

Properties

  • Space: O(n + e) — n heads plus 2e nodes (undirected) or e nodes (directed).
  • List all neighbours of u in O(deg(u)) — only real neighbours are visited. This makes BFS and DFS fast.
  • Check “is there an edge u–v?” needs a scan of u's list: O(deg(u)).
  • In-degree in a digraph is slow: you must scan every list (or keep an inverse list).
Program 2 — adjacency list with linked lists
/* Adjacency list using linked lists (new node added at the end) */
#include <stdio.h>
#include <stdlib.h>
#define MAX 20

struct node {
    int vertex;
    struct node *next;
};

struct node *head[MAX];
int n;

void addEdge(int u, int v) {
    struct node *p, *nn = (struct node *)malloc(sizeof(struct node));
    nn->vertex = v;
    nn->next = NULL;
    if (head[u] == NULL) {
        head[u] = nn;
        return;
    }
    p = head[u];
    while (p->next != NULL) p = p->next;
    p->next = nn;
}

void display() {
    int i;
    struct node *p;
    printf("\nAdjacency list:\n");
    for (i = 0; i < n; i++) {
        printf(" %c", 'A' + i);
        for (p = head[i]; p != NULL; p = p->next)
            printf(" -> %c", 'A' + p->vertex);
        printf(" -> NULL\n");
    }
}

int main() {
    int e, i, directed;
    char u, v;
    printf("Number of vertices: ");
    scanf("%d", &n);
    printf("Directed? (1 = yes, 0 = no): ");
    scanf("%d", &directed);
    printf("Number of edges: ");
    scanf("%d", &e);
    for (i = 0; i < e; i++) {
        printf("Edge %d (e.g. A B): ", i + 1);
        scanf(" %c %c", &u, &v);
        addEdge(u - 'A', v - 'A');
        if (!directed) addEdge(v - 'A', u - 'A');
    }
    display();
    return 0;
}

4.3Incidence matrix

Definition

The incidence matrix is an n × e array (rows = vertices, columns = edges). M[v][k] = 1 if edge k touches vertex v, otherwise 0. For a digraph, use +1 at the start (tail) and −1 at the end (head) of the edge.

Space is n × e, which is large for most graphs, so the incidence matrix is used mainly in theory and in electrical circuit analysis (Kirchhoff's laws).

4.4Edge list

The simplest form: just store every edge as a pair (u, v), or a triple (u, v, w) for a weighted graph. Space is O(e).

Finding neighbours is slow (scan all edges), but sorting edges by weight is easy. That is exactly what Kruskal's algorithm needs, so Kruskal uses an edge list.

Exam tip: Example — a road map of 1000 cities with about 3000 roads. Matrix: 1,000,000 cells. List: 1000 + 6000 = 7000 nodes. The list is over 100 times smaller, so use the list.

Remember from Part 4

  • Adjacency matrix: n × n, A[u][v] = 1 if edge. Symmetric for undirected graphs. Edge check O(1), space O(n²).
  • Adjacency list: array of linked lists. Space O(n + e). Best for sparse graphs and traversals.
  • Incidence matrix: n × e, vertex vs edge.
  • Edge list: list of (u, v, w). Used by Kruskal.
