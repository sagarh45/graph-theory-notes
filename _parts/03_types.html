Unit V · Part 3

Types of Graph

Each type is a separate section. Learn the rule, then the example drawn next to it. One graph can have more than one name — say which rule you used.

Syllabus: null, trivial, simple, multigraph, pseudograph, undirected, directed, weighted, regular, complete, path, cycle, star, wheel, bipartite, complete bipartite, connected, disconnected, strongly connected, weakly connected, cyclic, acyclic, DAG, tree, forest, isomorphic, planar.

3.1Null graph

Vertices, but no edges. Every vertex is isolated.

Example. Four cities and no roads yet.

|E| = 0

3.2Trivial graph

Exactly one vertex and no edge. It is a null graph with n = 1.

Example. A single computer, not yet joined to a network.

n = 1, |E| = 0

3.3Simple graph

At most one edge between any pair, and no loop. This is what “graph” means in most questions.

Example. The drawing has 5 edges, no pair repeated, no loop.

no loops · no parallel edges

3.4Multigraph

Parallel edges are allowed. Loops are not.

Example. Two train lines between the same two cities, drawn as two A–B edges.

parallel edges allowed

3.5Pseudograph

Both parallel edges and loops are allowed. This is the most general undirected graph.

Example. Two roads A–B, plus a loop at C (a road that leaves C and returns to C).

loops + parallel edges

3.6Undirected graph

Edges have no direction. (u, v) is the same edge as (v, u). You may travel both ways.

Example. A two-way road between A and B.

3.7Directed graph

Every edge is an arrow. <u, v> is not the same as <v, u>. Also called a digraph.

Example. One-way streets. You can go A → B, but not B → A, unless a second arrow is drawn.

3.8Weighted graph

Every edge has a number: distance, time or cost. A weighted graph may be directed or undirected.

Example. A–B costs 4, B–C costs 2. Path A–B–C has total weight 6 and length 2.

weight on every edge

3.9Regular graph

Every vertex has the same degree k. This cycle is 2-regular. A k-regular graph on n vertices has nk/2 edges, so nk must be even.

Example. A hexagon: every corner has degree 2. It is regular, but not complete.

deg(v) = k for every v

3.10Complete graph

Kn: every vertex is joined to every other vertex by exactly one edge. Kn has n(n − 1)/2 edges and is (n − 1)-regular. Every complete graph is regular. Not every regular graph is complete.

Example. K4 has 6 edges. Each vertex has degree 3.

|E| = n(n − 1)/2

3.11Path graph

Pn is n vertices in one line. The two ends have degree 1. The others have degree 2. It is a tree, so it has n − 1 edges.

Example. P5 is drawn. It is not a cycle, because the ends are not joined.

Pₙ has n − 1 edges

3.12Cycle graph

Cn is one cycle through all n vertices. It has n edges and is 2-regular. C3 = K3. An even cycle is bipartite. An odd cycle is not.

Example. C5 is drawn. It is regular, not complete, and not bipartite.

Cₙ has n edges

3.13Star

K1,n: one centre joined to n leaves, and no other edges. It is a tree and a complete bipartite graph.

Example. K1,4. The centre has degree 4. Each leaf has degree 1.

centre degree n

3.14Wheel

A cycle plus one hub joined to every vertex of the cycle. The hub has the highest degree.

Example. A 4-cycle with hub E. E has degree 4. This is not a tree: it has cycles.

cycle + one hub

3.15Bipartite graph

Vertices split into two groups so that every edge goes from one group to the other. No edge stays inside a group.

Test: bipartite if and only if there is no odd cycle.

Example. Students {A, B, C} and courses {X, Y, Z}. An edge means “enrolled in”.

no odd cycle

3.16Complete bipartite graph

Km,n: every vertex of the first group is joined to every vertex of the second group, and there are no edges inside a group. It has m × n edges.

Example. K2,3 has 2 × 3 = 6 edges. A star is K1,n.

|E| = m · n

3.17Connected graph

An undirected graph with a path between every pair of vertices. It has exactly one component.

Example. The square is connected. From any corner you can walk to any other.

1 component

3.18Disconnected graph

At least one pair of vertices has no path between them. The pieces are the components.

Example. {A, B, C} and {D, E} are two components. There is no path from A to D.

2 or more components

3.19Strongly connected graph

A directed graph in which every vertex can reach every other vertex by following the arrows.

Example. A → B → C → D → A. From any start you can go all the way round.

path both ways, following arrows

3.20Weakly connected graph

Not strongly connected, but it becomes connected if you ignore the arrows.

Example. Nothing leaves B, so B cannot reach A. Ignore the arrows and it is one piece. Strongly connected implies weakly connected. The reverse is false.

ignore arrows → connected

3.21Cyclic graph

Contains at least one cycle.

Example. A–B–C–A is a cycle, so the graph is cyclic. D is outside the cycle, but one cycle is enough.

has a cycle

3.22Acyclic graph

Contains no cycle. Every tree and every forest is acyclic. A single edge is acyclic.

Example. This path has no way back to an earlier vertex without repeating an edge.

no cycle

3.23DAG

A directed acyclic graph: arrows, and no directed cycle. Used for task order, course plans and build tools. Every DAG has a topological order.

Example. A and B have no arrow into them. Nothing leads back, so there is no directed cycle.

directed · no directed cycle

3.24Tree

Connected and acyclic. Exactly one path between any two vertices. A tree with n vertices has n − 1 edges.

Example. 6 vertices, 5 edges, no cycle. D, E and F are leaves.

n − 1 edges

3.25Forest

An acyclic graph that may be disconnected: a set of trees. A forest with n vertices and c trees has n − c edges.

Example. Three trees: {A, B, C}, {D, E}, and {F}. 6 vertices, 3 trees, 3 edges.

n − c edges

3.26Isomorphic graphs

Two graphs are isomorphic if renaming the vertices of one gives the other. Same structure, different drawing.

Example. Map 1→Q, 2→P, 3→S, 4→R onto a diamond with one diagonal. Same vertices, same edges, same degree sequence 3, 3, 2, 2. Equal counts are necessary, not enough — give the mapping.

same structure

3.27Planar graph

A graph that can be drawn with no two edges crossing. K4 looks crossed in a square, but it can be redrawn with one vertex inside and no crossing, so K4 is planar. K5 and K3,3 are not planar.

Example. This drawing of K4 has no crossing.

drawable with no crossing

3.30Name the graph — ten examples

Cover the right column and try each one. A graph can have more than one name: K3 is also C3, a complete graph, and 2-regular.

1. Three vertices, no edges

Null graph on 3 vertices. Every vertex is isolated. It is also 0-regular.

2. Triangle

K3 and C3. Complete, 2-regular, a cycle, and not bipartite (odd cycle).

3. Square

C4. 2-regular, bipartite (groups {A, C} and {B, D}), not complete.

4. One centre, three leaves

Star K1,3. A tree (3 edges, 4 vertices). Bipartite. Not regular.

5. Two edges between A and B

Multigraph, not simple. deg(A) = 2, deg(B) = 3, deg(C) = 1.

6. A loop and a separate edge

Pseudograph (the loop). Two components: {A} and {B, C}. deg(A) = 2.

7. A directed triangle

Strongly connected: follow the arrows all the way round. Also a directed cycle.

8. Arrows, no way back

A DAG (no directed cycle). Weakly connected. A is a source, C is a sink. Topological order A, B, C.

9. Numbers on the edges

Weighted path. Total weight A to D = 5 + 1 + 8 = 14. Still a tree.

10. Connected, one extra edge

Not a tree: 5 vertices and 5 edges, so exactly one cycle (A–B–D–C–A). E is pendant. D is a cut vertex; D–E is a bridge.

Do not mix the names. Regular does not mean complete. Connected does not mean strongly connected. A cycle graph is 2-regular, but a 3-regular graph need not be a cycle. Always state the rule you used.

Remember from Part 3

  • Simple = no loops and no parallel edges. Multigraph allows parallel edges; pseudograph allows loops too.
  • Complete Kn: n(n − 1)/2 edges, (n − 1)-regular.
  • Bipartite ⇔ no odd cycle.
  • Strongly connected: follow arrows from anyone to anyone. Weakly: only if you ignore arrows.
  • Isomorphic = same structure; prove with a vertex mapping.
  • Pₙ is a path (n − 1 edges). Cₙ is a cycle (n edges, 2-regular). A star is K1,n.
