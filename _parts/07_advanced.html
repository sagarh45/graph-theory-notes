Advanced Graph Algorithms

What to do when weights are negative, when you need the distance between every pair, and how to find cycles, weak points, groups and colourings in a graph. Every algorithm has a step player.

7.1Bellman–Ford: shortest path with negative weights

Why do we need it? Dijkstra fixes a vertex for ever as soon as it is the closest one. With a negative edge, a cheaper path can appear later, and Dijkstra misses it.

Definition

Bellman–Ford finds the shortest distance from one source s to every vertex. Edge weights may be negative. It also reports a negative cycle if one can be reached from s.

In simple words

Don't be clever, be patient. Relax every edge, then do it again, and again. A shortest path has at most n − 1 edges, so after n − 1 rounds every distance is correct. If a round n can still improve something, there must be a loop that keeps getting cheaper — a negative cycle.

BELLMAN-FORD(G, s)
1. dist[v] = ∞, prev[v] = NIL for every v;   dist[s] = 0
2. Repeat n − 1 times:                    // one "pass"
     For every edge (u, v) with weight w:
         If dist[u] + w < dist[v]:         // RELAX
             dist[v] = dist[u] + w;  prev[v] = u
     (if nothing changed in this pass, stop early)
3. For every edge (u, v):                 // extra check
     If dist[u] + w < dist[v]:  report "negative cycle"
Passdist ABCDE
Start0∞∞∞∞
After pass 106472
After pass 202472
After pass 30247−2
After pass 40247−2

Edges are relaxed in the order A→B, A→D, B→C, B→D, B→E, C→B, D→C, D→E, E→A, E→C. The shortest path to E is A → D → C → B → E = 7 − 3 − 2 − 4 = −2. A different edge order gives the same final answer, but the in-between rows can change.

Negative cycle

If a cycle has a negative total, you can go round it forever and the cost keeps falling. Then "shortest path" has no meaning. Bellman–Ford catches this with the extra pass.

Program 9 — Bellman–Ford with negative-cycle check
/* Bellman-Ford shortest paths (negative weights allowed), O(V * E) */
#include <stdio.h>
#include <limits.h>
#define MAX 20
#define MAXE 100

struct Edge { int u, v, w; } E[MAXE];
int n, e;

void printPath(int prev[], int v) {
    if (prev[v] != -1) {
        printPath(prev, prev[v]);
        printf(" -> ");
    }
    printf("%c", 'A' + v);
}

void bellmanFord(int s) {
    int dist[MAX], prev[MAX];
    int i, j, pass, changed;
    for (i = 0; i < n; i++) {
        dist[i] = INT_MAX;
        prev[i] = -1;
    }
    dist[s] = 0;
    for (pass = 1; pass <= n - 1; pass++) {       /* relax every edge n-1 times */
        changed = 0;
        for (j = 0; j < e; j++) {
            int u = E[j].u, v = E[j].v, w = E[j].w;
            if (dist[u] != INT_MAX && dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                prev[v] = u;
                changed = 1;
            }
        }
        if (!changed) break;                      /* nothing improved: stop early */
    }
    for (j = 0; j < e; j++)                       /* one more pass: negative cycle? */
        if (dist[E[j].u] != INT_MAX && dist[E[j].u] + E[j].w < dist[E[j].v]) {
            printf("\nNegative cycle found: shortest paths are not defined.\n");
            return;
        }
    printf("\nPasses used: %d\n", pass > n - 1 ? n - 1 : pass);
    printf("Vertex  Distance  Path\n");
    for (i = 0; i < n; i++) {
        if (dist[i] == INT_MAX) { printf("  %c     unreachable\n", 'A' + i); continue; }
        printf("  %c     %4d      ", 'A' + i, dist[i]);
        printPath(prev, i);
        printf("\n");
    }
}

int main() {
    int i, w;
    char u, v, s;
    printf("Number of vertices: ");
    scanf("%d", &n);
    printf("Number of directed edges: ");
    scanf("%d", &e);
    for (i = 0; i < e; i++) {
        printf("Edge %d (u v weight): ", i + 1);
        scanf(" %c %c %d", &u, &v, &w);
        E[i].u = u - 'A'; E[i].v = v - 'A'; E[i].w = w;
    }
    printf("Source vertex: ");
    scanf(" %c", &s);
    bellmanFord(s - 'A');
    return 0;
}

7.2Floyd–Warshall: shortest path between every pair

Definition

Floyd–Warshall computes the shortest distance between every pair of vertices (i, j) using a distance matrix D. Negative edges are allowed, negative cycles are not.

In simple words

Take the cities one by one. For city k ask every pair (i, j): "Is it shorter to go from i to j by passing through k?" If yes, write the new smaller number in the table. After you have tried every k, the table is complete.

Dk[i][j] = min( Dk−1[i][j],  Dk−1[i][k] + Dk−1[k][j] )

FLOYD-WARSHALL(W)
1. D = W        // D[i][i] = 0, D[i][j] = weight, or ∞ if no edge
2. For k = 1 to n:                // k = the allowed middle vertex
     For i = 1 to n:
         For j = 1 to n:
             If D[i][k] + D[k][j] < D[i][j]:
                 D[i][j] = D[i][k] + D[k][j]
3. Return D

Exam tip: The k loop must be the outermost. In each round k, row k and column k never change, so copy them first and fill only the other cells — it saves time. Write all matrices D⁰, D¹, … Dⁿ.
  • Time O(n³), space O(n²). Simple code, great for small dense graphs.
  • Running Dijkstra from every vertex costs O(n · (n + e) log n) — better for big sparse graphs with no negative edges.
  • A negative number on the diagonal at the end means a negative cycle.
  • With 0/1 values and OR/AND instead of min/+, the same loops give Warshall's transitive closure (can i reach j at all?).
Program 10 — Floyd–Warshall
/* Floyd-Warshall: shortest distance between every pair, O(V^3) */
#include <stdio.h>
#define MAX 20
#define INF 99999

int D[MAX][MAX];
int n;

void printMatrix(const char *title) {
    int i, j;
    printf("\n%s\n    ", title);
    for (j = 0; j < n; j++) printf("%4c", 'A' + j);
    printf("\n");
    for (i = 0; i < n; i++) {
        printf("%c : ", 'A' + i);
        for (j = 0; j < n; j++) {
            if (D[i][j] >= INF) printf("   -");
            else printf("%4d", D[i][j]);
        }
        printf("\n");
    }
}

void floyd() {
    int i, j, k;
    for (k = 0; k < n; k++)                 /* allow vertex k as a middle stop */
        for (i = 0; i < n; i++)
            for (j = 0; j < n; j++)
                if (D[i][k] < INF && D[k][j] < INF && D[i][k] + D[k][j] < D[i][j])
                    D[i][j] = D[i][k] + D[k][j];
}

int main() {
    int e, i, j, w;
    char u, v;
    printf("Number of vertices: ");
    scanf("%d", &n);
    for (i = 0; i < n; i++)
        for (j = 0; j < n; j++)
            D[i][j] = (i == j) ? 0 : INF;
    printf("Number of directed edges: ");
    scanf("%d", &e);
    for (i = 0; i < e; i++) {
        printf("Edge %d (u v weight): ", i + 1);
        scanf(" %c %c %d", &u, &v, &w);
        D[u - 'A'][v - 'A'] = w;
    }
    printMatrix("Initial matrix D0 (- = no edge):");
    floyd();
    printMatrix("Shortest distances:");
    return 0;
}

7.3Cycle detection

Many questions start with "does this graph have a cycle?" — a tree must not have one, a topological order needs none, a deadlock is one. The answer is a small change to DFS, and the rule is different for undirected and directed graphs.

GraphCycle exists if DFS…Why the extra rule
Undirectedmeets a visited vertex that is not the parentThe edge back to the parent is the same edge we came along, not a loop.
Directedmeets a grey vertex (still on the current path)A black (finished) vertex can be reached by two paths without any cycle, e.g. A→B→D and A→C→D.

Watch the step where C→D reaches D. D is still grey, so D → E → C → D is a cycle. DFS can stop at the first back edge — one is enough to prove a cycle.

Other ways to detect a cycle:

  • Undirected, union-find (like Kruskal): for each edge, if both ends are already in the same set → cycle.
  • Directed, Kahn's topological sort: if fewer than n vertices come out, the rest are on a cycle (see 6.5).
  • Quick count: a connected undirected graph with e ≥ n edges always has a cycle (a tree has only n − 1).
Program 11 — Cycle detection in a directed graph (DFS colours)
/* Cycle detection in a directed graph using DFS colours
   0 = white (not visited), 1 = grey (on the current path), 2 = black (finished) */
#include <stdio.h>
#define MAX 20

int adj[MAX][MAX], color[MAX], parent[MAX];
int n;

int dfs(int u) {
    int v, x;
    color[u] = 1;                                   /* grey: on the path */
    for (v = 0; v < n; v++) {
        if (!adj[u][v]) continue;
        if (color[v] == 1) {                        /* back edge -> cycle */
            printf("Cycle found: %c", 'A' + v);
            {   int path[MAX], k = 0;
                for (x = u; x != v; x = parent[x]) path[k++] = x;
                while (k > 0) printf(" -> %c", 'A' + path[--k]);
            }
            printf(" -> %c\n", 'A' + v);
            return 1;
        }
        if (color[v] == 0) {
            parent[v] = u;
            if (dfs(v)) return 1;
        }
    }
    color[u] = 2;                                   /* black: finished */
    return 0;
}

int main() {
    int e, i;
    char u, v;
    printf("Number of vertices: ");
    scanf("%d", &n);
    printf("Number of directed edges: ");
    scanf("%d", &e);
    for (i = 0; i < e; i++) {
        printf("Edge %d (u v): ", i + 1);
        scanf(" %c %c", &u, &v);
        adj[u - 'A'][v - 'A'] = 1;
    }
    printf("\n");
    for (i = 0; i < n; i++) {
        if (color[i] == 0) {
            parent[i] = -1;
            if (dfs(i)) return 0;
        }
    }
    printf("No cycle: the graph is a DAG.\n");
    return 0;
}

7.4Connected components and bipartite check

Counting components is the simplest use of BFS or DFS: go through the vertices; every time you find an unvisited one, start a new search and give everything it reaches the same number (colour).

Theorem

A graph is bipartite if and only if it has no cycle of odd length.

In simple words

Colour the start white. Its neighbours must be dark, their neighbours white, and so on. If an edge ever joins two vertices of the same colour, you are stuck — that edge closes an odd cycle. BFS does this colouring level by level: even levels = X, odd levels = Y.

Uses: matching students to projects, jobs to machines (both are bipartite graphs); checking if a 2-slot timetable is possible; Kₘ,ₙ problems.

7.5Bridges and articulation points

Bridge (cut edge)

An edge whose removal increases the number of connected components.

Articulation point (cut vertex)

A vertex whose removal (with its edges) increases the number of components.

Slow way: remove each edge (or vertex) and run DFS again — O(e · (n + e)). Fast way (Tarjan): one DFS that stores two numbers for each vertex.

  • disc[u] — the time DFS first reached u (1, 2, 3, …).
  • low[u] — the smallest disc that u's subtree can reach using at most one back edge. It tells us how high the subtree can "climb back".
Test (v is a DFS child of u)Meaning
low[v] > disc[u] → u–v is a bridgeNothing under v can climb back to u or above, so u–v is the only link.
u not root and low[v] ≥ disc[u] → u is a cut vertexThe subtree of v cannot get above u without going through u.
u is root with ≥ 2 DFS children → u is a cut vertexThe children's subtrees are joined only through the root.

Why care? In a computer or road network, a bridge is a single cable or road whose failure splits the network, and a cut vertex is a single router or junction. Engineers add backup links exactly there.

Program 12 — Bridges and cut vertices (Tarjan)
/* Bridges and articulation points (cut vertices) with Tarjan's DFS, O(V + E) */
#include <stdio.h>
#define MAX 20

int adj[MAX][MAX], disc[MAX], low[MAX], parent[MAX], isCut[MAX];
int n, timer = 0;

int min(int a, int b) { return a < b ? a : b; }

void dfs(int u) {
    int v, children = 0;
    disc[u] = low[u] = ++timer;
    for (v = 0; v < n; v++) {
        if (!adj[u][v]) continue;
        if (disc[v] == 0) {                       /* tree edge */
            children++;
            parent[v] = u;
            dfs(v);
            low[u] = min(low[u], low[v]);
            if (low[v] > disc[u])
                printf("Bridge: %c - %c\n", 'A' + u, 'A' + v);
            if (parent[u] != -1 && low[v] >= disc[u])
                isCut[u] = 1;
        } else if (v != parent[u]) {              /* back edge */
            low[u] = min(low[u], disc[v]);
        }
    }
    if (parent[u] == -1 && children >= 2)         /* root rule */
        isCut[u] = 1;
}

int main() {
    int e, i;
    char u, v;
    printf("Number of vertices: ");
    scanf("%d", &n);
    printf("Number of edges: ");
    scanf("%d", &e);
    for (i = 0; i < e; i++) {
        printf("Edge %d (u v): ", i + 1);
        scanf(" %c %c", &u, &v);
        adj[u - 'A'][v - 'A'] = adj[v - 'A'][u - 'A'] = 1;
    }
    printf("\n");
    for (i = 0; i < n; i++)
        if (disc[i] == 0) { parent[i] = -1; dfs(i); }
    printf("Cut vertices:");
    for (i = 0; i < n; i++) if (isCut[i]) printf(" %c", 'A' + i);
    printf("\n\nVertex  disc  low\n");
    for (i = 0; i < n; i++) printf("  %c     %2d   %2d\n", 'A' + i, disc[i], low[i]);
    return 0;
}

7.6Strongly connected components (SCC)

Definition

In a directed graph, a strongly connected component is a largest group of vertices in which every vertex can reach every other by following the arrows.

Kosaraju's algorithm — two DFS passes:

KOSARAJU(G)
1. Run DFS on G. When a vertex FINISHES, push it on a stack.
2. Build Gᵀ: reverse every edge.
3. While the stack is not empty:
     u = POP()
     If u is not visited in pass 2:
         DFS(Gᵀ, u)  — every vertex reached is ONE SCC
Why reverse the edges?

The vertex that finishes last sits in a "source" SCC. In the reversed graph, that SCC has no way out, so DFS from it stays inside and collects exactly that one SCC. Then the next one, and so on.

Tarjan's SCC algorithm does the same job in a single DFS using the low[] idea of 7.5. Both are O(n + e). Uses: finding groups of web pages that link to each other, circular dependencies in software, 2-SAT.

Program 13 — Strongly connected components (Kosaraju)
/* Strongly connected components with Kosaraju's algorithm, O(V + E)
   Pass 1: DFS on G, push each vertex when it finishes.
   Pass 2: DFS on the reversed graph in reverse finish order. */
#include <stdio.h>
#define MAX 20

int adj[MAX][MAX], visited[MAX], stack[MAX], top = -1;
int n;

void dfs1(int u) {
    int v;
    visited[u] = 1;
    for (v = 0; v < n; v++)
        if (adj[u][v] && !visited[v]) dfs1(v);
    stack[++top] = u;                       /* finished: push */
}

void dfs2(int u) {                          /* uses reversed edges: adj[v][u] */
    int v;
    visited[u] = 1;
    printf(" %c", 'A' + u);
    for (v = 0; v < n; v++)
        if (adj[v][u] && !visited[v]) dfs2(v);
}

int main() {
    int e, i, count = 0;
    char u, v;
    printf("Number of vertices: ");
    scanf("%d", &n);
    printf("Number of directed edges: ");
    scanf("%d", &e);
    for (i = 0; i < e; i++) {
        printf("Edge %d (u v): ", i + 1);
        scanf(" %c %c", &u, &v);
        adj[u - 'A'][v - 'A'] = 1;
    }
    for (i = 0; i < n; i++)
        if (!visited[i]) dfs1(i);
    printf("\nFinish order:");
    for (i = 0; i <= top; i++) printf(" %c", 'A' + stack[i]);
    printf("\n");
    for (i = 0; i < n; i++) visited[i] = 0;
    while (top >= 0) {
        int x = stack[top--];
        if (!visited[x]) {
            printf("SCC %d:", ++count);
            dfs2(x);
            printf("\n");
        }
    }
    printf("Number of SCCs = %d\n", count);
    return 0;
}

7.7Euler and Hamiltonian paths

In 1736 the city of Königsberg had 7 bridges joining 4 land areas. People asked: can you walk across every bridge exactly once? Euler proved it is impossible — and invented graph theory.

Connected graphEuler circuit (start = end)Euler path (start ≠ end)
UndirectedEvery vertex has even degreeExactly 2 vertices have odd degree (start at one, end at the other)
Directedin(v) = out(v) for every vOne vertex out = in + 1 (start), one in = out + 1 (end), all others equal

Hierholzer's method is O(e). The older Fleury's method also works: at each step take any unused edge, but never cross a bridge of the remaining graph unless you have no other choice.

Hamiltonian path and cycle

Definition

A Hamiltonian path visits every vertex exactly once. A Hamiltonian cycle also returns to the start.

EulerHamiltonian
Uses every…edge oncevertex once
Easy test?Yes — count odd degreesNo known fast test (NP-complete)
Find itO(e)Backtracking, O(n!) worst case
Real problemPostman route, drawing puzzlesTravelling salesman, tours

Sufficient conditions (if true, a Hamiltonian cycle surely exists, n ≥ 3):

  • Dirac: every vertex has degree ≥ n/2.
  • Ore: deg(u) + deg(v) ≥ n for every non-adjacent pair u, v.
  • Kn always has one.

7.8Graph colouring

Definition

A proper colouring gives each vertex a colour so that no edge joins two vertices of the same colour. The smallest number of colours needed is the chromatic number χ(G).

Graphχ(G)
No edges (null graph)1
Bipartite with at least one edge (trees, even cycles)2
Odd cycle C2k+13
Complete graph Knn
Any planar graph (map)≤ 4 (Four Colour Theorem)
Any graph with largest degree Δ≤ Δ + 1 (greedy always achieves this)
WELSH-POWELL(G)
1. Sort the vertices by degree, largest first.
2. For each vertex v in this order:
     Give v the smallest colour number not used by any coloured neighbour.

This graph is a wheel: hub C joined to the 5-cycle A–B–E–F–D. The rim is an odd cycle (needs 3 colours) and the hub touches all of it (one more), so χ = 4 and greedy found the best answer here. On other graphs greedy can use more colours than needed — finding χ exactly is NP-hard.

Real use: exam timetable

Each subject is a vertex. Join two subjects if some student takes both. A colouring = a timetable: same colour = same time slot, and no student has two exams at once. χ(G) = the fewest slots. The same idea assigns CPU registers, radio frequencies and Sudoku digits.

Program 14 — Greedy colouring (Welsh–Powell)
/* Greedy graph colouring (Welsh-Powell order: highest degree first) */
#include <stdio.h>
#define MAX 20

int adj[MAX][MAX], deg[MAX], order[MAX], color[MAX];
int n;

int main() {
    int e, i, j, k, c, used[MAX], maxc = 0;
    char u, v;
    printf("Number of vertices: ");
    scanf("%d", &n);
    printf("Number of edges: ");
    scanf("%d", &e);
    for (i = 0; i < e; i++) {
        printf("Edge %d (u v): ", i + 1);
        scanf(" %c %c", &u, &v);
        adj[u - 'A'][v - 'A'] = adj[v - 'A'][u - 'A'] = 1;
    }
    for (i = 0; i < n; i++) {
        deg[i] = 0;
        for (j = 0; j < n; j++) deg[i] += adj[i][j];
        order[i] = i;
        color[i] = -1;
    }
    for (i = 0; i < n - 1; i++)               /* sort by degree, largest first (stable) */
        for (j = 0; j < n - 1 - i; j++)
            if (deg[order[j]] < deg[order[j + 1]]) {
                int t = order[j]; order[j] = order[j + 1]; order[j + 1] = t;
            }
    printf("\nOrder:");
    for (i = 0; i < n; i++) printf(" %c(%d)", 'A' + order[i], deg[order[i]]);
    printf("\n");
    for (k = 0; k < n; k++) {
        int x = order[k];
        for (c = 0; c < n; c++) used[c] = 0;
        for (j = 0; j < n; j++)               /* colours taken by neighbours */
            if (adj[x][j] && color[j] != -1) used[color[j]] = 1;
        for (c = 0; used[c]; c++);            /* smallest free colour */
        color[x] = c;
        if (c + 1 > maxc) maxc = c + 1;
        printf("%c gets colour %d\n", 'A' + x, c + 1);
    }
    printf("Colours used = %d\n", maxc);
    return 0;
}

Remember from Part 7

  • Bellman–Ford: n − 1 passes over all edges; an n-th improvement means a negative cycle. O(n · e).
  • Floyd–Warshall: D[i][j] = min(D[i][j], D[i][k] + D[k][j]) with k outermost. O(n³).
  • Cycle: undirected → visited non-parent; directed → grey vertex.
  • Bipartite ⇔ no odd cycle ⇔ χ ≤ 2.
  • Bridge: low[v] > disc[u]. Cut vertex: low[v] ≥ disc[u] (root: 2+ children).
  • SCC (Kosaraju): DFS for finish order, reverse edges, DFS in reverse finish order.
  • Euler: 0 odd vertices → circuit, 2 → path. Hamiltonian: no easy test.
