R.3Common mistakes

1. Path length is the number of edges, not vertices.
2. A self-loop adds 2 to the degree in an undirected graph.
3. In BFS mark a vertex visited when it is enqueued, or it may enter the queue twice.
4. BFS/DFS order depends on the neighbour order. State “neighbours taken in alphabetical order”.
5. For a disconnected graph, one BFS/DFS does not reach everything — restart from an unvisited vertex.
6. Weakly connected is not strongly connected. Check that arrows allow travel both ways.
7. Same vertex count, edge count and degrees do not prove two graphs are isomorphic. Give the mapping.
8. Dijkstra fails with negative weights; topological sort fails on any directed cycle.
9. In Floyd–Warshall the k loop is outermost. Putting i or j outside gives wrong answers.
10. Bridge test uses > (low[v] > disc[u]); cut-vertex test uses ≥. The DFS root is a cut vertex only if it has 2 or more children.
11. Euler = every edge once; Hamiltonian = every vertex once. Do not mix them.

R.4Model answers

Q1Define a graph. Differentiate between directed and undirected graphs. (5 marks)

A graph G = (V, E) is a non-linear data structure made of a finite non-empty set V of vertices and a set E of edges, where each edge connects a pair of vertices.

In an undirected graph each edge is an unordered pair (u, v) = (v, u) and can be travelled both ways; its adjacency matrix is symmetric; each vertex has one degree; maximum edges n(n − 1)/2. In a directed graph each edge is an ordered pair <u, v> from tail u to head v and can be travelled one way only; its matrix need not be symmetric; each vertex has an in-degree and an out-degree; maximum edges n(n − 1). Draw one small example of each.

Q2Explain the following terms with an example: degree, path, cycle, loop, multiple edges, connected graph.

Use Figure 1 of Part 1. Degree = edges at a vertex, deg(B) = 3. Path = sequence of adjacent vertices without repetition, A–B–D–F. Cycle = path returning to its start, B–C–E–D–B. Loop = edge (v, v). Multiple edges = two or more edges between the same pair. Connected graph = a path exists between every pair of vertices.

Q3Prove that the number of odd-degree vertices in any graph is even.

By the handshake lemma Σ deg(v) = 2e, which is even. Split the sum into even-degree vertices and odd-degree vertices. The even part is even, so the odd part = 2e − (even) is also even. A sum of odd numbers is even only when there is an even count of them. Hence the number of odd-degree vertices is even. ∎

Q7Write a C function for DFS. What is its time complexity?

The recursive dfs() of Program 4: mark visited, print, recurse on each unvisited neighbour. Time O(n²) with an adjacency matrix because each call scans a full row; O(n + e) with an adjacency list. Space O(n) for visited[] and the recursion stack.

Use the table in 5.6: queue vs stack, level order vs depth order, both O(n + e), BFS gives shortest unweighted path, DFS detects cycles with back edges, applications of each.

Q·A2Find all-pairs shortest paths using Floyd–Warshall. (10 marks)

Write the recurrence Dk[i][j] = min(Dk−1[i][j], Dk−1[i][k] + Dk−1[k][j]). Write D⁰ from the graph, then D¹ … Dⁿ — in each, copy row k and column k unchanged and check the remaining cells. Circle the changed cells. State O(n³) time and O(n²) space.

Q·A3What are articulation points and bridges? How are they found? (5 marks)

Give both definitions with the figure of 7.5. Explain disc and low, then the three rules (bridge: low[v] > disc[u]; cut vertex: low[v] ≥ disc[u] for a non-root; root with ≥ 2 children). One DFS, O(n + e). Mention network reliability as the use.

Q·A4State the conditions for an Euler path and circuit. Explain the Königsberg bridge problem.

Draw the 4-vertex multigraph with 7 edges. Degrees 5, 3, 3, 3 → four odd vertices → no Euler path. Rule: connected and 0 odd vertices → circuit; exactly 2 odd → path from one odd vertex to the other. Contrast with Hamiltonian (every vertex once, NP-complete).
