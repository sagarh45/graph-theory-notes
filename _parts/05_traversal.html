Unit V · Part 5

Graph Traversal: BFS and DFS

Traversal means visiting every vertex exactly once. BFS spreads out level by level using a queue. DFS goes deep first using a stack. Watch both run step by step.

Syllabus: Graph traversal — Breadth First Search and Depth First Search, algorithms, programs and comparison.

5.1Why traversal needs a visited[] array

In a tree you can never come back to a node you already saw. A graph can have cycles: from A you go to B, from B to C, and from C back to A. Without a record, the traversal would go round forever.

Keep an array visited[n], all 0 at the start. Set visited[v] = 1 the moment you first reach v, and never process v again.
BFS — Breadth First Search

Like ripples on water: visit the start, then all vertices 1 edge away, then all 2 edges away, and so on. Uses a queue.

DFS — Depth First Search

Like walking through a maze: keep going forward as deep as you can; when you hit a dead end, go back one step and try another way. Uses a stack (or recursion).

Order rule used in these notes and in most exams: when a vertex has several unvisited neighbours, take them in alphabetical (or numerical) order, which is the order in the adjacency matrix row. A different neighbour order gives a different but still correct traversal — always state your order.
Queue — used by BFS

First in, first out. The vertex that has waited longest leaves first (the front). A new vertex joins at the rear.

enqueue A → [ A ]
dequeue A, enqueue B, C → [ B C ]

Stack — used by DFS

Last in, first out. The vertex pushed last sits on top and is the next one popped. Recursion uses the same idea: the call stack.

push A → [ A ]
pop A, push C then B → [ C B ]
pop B (B was last)

Mark a vertex visited when it first enters the queue (BFS) or when you print it after a pop (stack DFS). If you wait too long, the same vertex is stored twice.

5.2Breadth First Search (BFS)

BFS(G, s)
1. Set visited[v] = 0 for every vertex v.
2. visited[s] = 1;  ENQUEUE(s)
3. While the queue is not empty:
     u = DEQUEUE();  print u
     For every neighbour v of u (in order):
         If visited[v] == 0:
             visited[v] = 1;  ENQUEUE(v)
4. Stop.

Dry run table (write this in the exam)

Common mistake: Marking a vertex visited only when it is dequeued. Then the same vertex can enter the queue twice (for example F from both C and E). Mark it visited when you enqueue it.

What BFS gives you for free

  • Shortest path in an unweighted graph: the level of v is the fewest edges from s to v. Follow the thick BFS-tree edges back to s to get the path.
  • BFS spanning tree: the thick edges form a tree that reaches every vertex in the component.
  • Connected components: start BFS again from any unvisited vertex; each new start is a new component.
  • Bipartite test: colour levels even/odd. If an edge joins two vertices of the same level, the graph is not bipartite.

5.3Depth First Search (DFS)

Recursive

DFS(u)
1. visited[u] = 1;  print u
2. For every neighbour v of u (in order):
       If visited[v] == 0:
           DFS(v)
3. Return.

With an explicit stack

DFS_STACK(s)
1. PUSH(s)
2. While the stack is not empty:
     u = POP()
     If visited[u] == 1: continue
     visited[u] = 1;  print u
     Push unvisited neighbours of u
       in REVERSE order (so the smallest
       is on top and comes out first)
3. Stop.

The label under each vertex shows discovery / finish time: when DFS first reached the vertex and when it finished all its neighbours. The side panel shows the call stack.

Practical-style example — vertices 0, 1, 2, 3

Same graph as the adjacency-matrix program in Part 4. Start BFS at 0. The queue holds vertex numbers, not letters.

BFS order = 0 1 2 3. After 0 is dequeued, 1 and 2 enter the queue. 3 is a neighbour of both, but it is marked visited when 1 enqueues it, so 2 does not enqueue it again.

DFS order = 0 1 3 2. Pop 0, push 2 then 1 (reverse order, so 1 is on top). Pop 1, push 3. Pop 3. Pop 2.

5.7Programs

Program 3 — BFS using a queue
/* Breadth First Search on an adjacency matrix */
#include <stdio.h>
#define MAX 20

int adj[MAX][MAX], visited[MAX];
int queue[MAX], front = 0, rear = -1;
int n;

void enqueue(int v) { queue[++rear] = v; }
int  dequeue()      { return queue[front++]; }
int  isEmpty()      { return front > rear; }

void bfs(int start) {
    int u, v;
    visited[start] = 1;
    enqueue(start);
    while (!isEmpty()) {
        u = dequeue();
        printf("%c ", 'A' + u);
        for (v = 0; v < n; v++) {          /* neighbours in order A, B, C ... */
            if (adj[u][v] == 1 && !visited[v]) {
                visited[v] = 1;            /* mark when enqueued, not when printed */
                enqueue(v);
            }
        }
    }
}

int main() {
    int e, i;
    char u, v, s;
    printf("Number of vertices: ");
    scanf("%d", &n);
    printf("Number of edges: ");
    scanf("%d", &e);
    for (i = 0; i < e; i++) {
        printf("Edge %d: ", i + 1);
        scanf(" %c %c", &u, &v);
        adj[u - 'A'][v - 'A'] = adj[v - 'A'][u - 'A'] = 1;
    }
    printf("Start vertex: ");
    scanf(" %c", &s);
    printf("\nBFS order: ");
    bfs(s - 'A');
    printf("\n");
    return 0;
}

Program 4 — DFS, recursive and with a stack
/* Depth First Search: recursive version and explicit-stack version */
#include <stdio.h>
#define MAX 20

int adj[MAX][MAX], visited[MAX];
int n;

void dfs(int u) {                         /* recursive: uses the call stack */
    int v;
    visited[u] = 1;
    printf("%c ", 'A' + u);
    for (v = 0; v < n; v++)
        if (adj[u][v] == 1 && !visited[v])
            dfs(v);
}

void dfsStack(int start) {                /* same order with our own stack */
    int stack[MAX * MAX], top = -1, u, v;
    stack[++top] = start;
    while (top >= 0) {
        u = stack[top--];                 /* pop */
        if (visited[u]) continue;
        visited[u] = 1;
        printf("%c ", 'A' + u);
        for (v = n - 1; v >= 0; v--)      /* push in reverse so A..Z come out first */
            if (adj[u][v] == 1 && !visited[v])
                stack[++top] = v;
    }
}

int main() {
    int e, i;
    char u, v, s;
    printf("Number of vertices: ");
    scanf("%d", &n);
    printf("Number of edges: ");
    scanf("%d", &e);
    for (i = 0; i < e; i++) {
        printf("Edge %d: ", i + 1);
        scanf(" %c %c", &u, &v);
        adj[u - 'A'][v - 'A'] = adj[v - 'A'][u - 'A'] = 1;
    }
    printf("Start vertex: ");
    scanf(" %c", &s);

    printf("\nDFS (recursive): ");
    dfs(s - 'A');

    for (i = 0; i < n; i++) visited[i] = 0;
    printf("\nDFS (stack)    : ");
    dfsStack(s - 'A');
    printf("\n");
    return 0;
}

Remember from Part 5

  • BFS = queue (front out, rear in), level by level. DFS = stack (top out) or recursion, deep first.
  • Mark visited when you enqueue (BFS) or when you first reach the vertex (DFS).
  • Both take O(V + E) with an adjacency list, O(V²) with a matrix.
  • BFS gives the fewest-edges path. A DFS back edge means a cycle.
  • Disconnected graph: restart from any unvisited vertex; count the restarts to count components.
