Unit V · Part 2

Graph Terminology

The words every graph question uses. Each term comes with a picture and a one-line meaning you can write in the exam.

Syllabus: Graph terminology — adjacent vertices and edges, degree, in-degree, out-degree, path, cycle, loop, multiple edges, connected graph.

2.1Adjacent, incident, neighbour

Adjacent vertices: two vertices joined by an edge. A and B are adjacent. A and D are not.

Neighbours of v: all vertices adjacent to v. Neighbours of B = {A, C, D}.

Incident edge: an edge is incident on the two vertices at its ends. Edge (B, D) is incident on B and on D.

Adjacent edges: two edges that share a common vertex. (A, B) and (B, D) are adjacent because both touch B.

Common mistake: Counting vertices as the length. The path A → B → D → F has 4 vertices but length 3. Length is always the number of edges.

2.4Loops and multiple edges

Self-loop: an edge that starts and ends at the same vertex, like (C, C). In an undirected graph a loop adds 2 to the degree, so deg(C) = 4 here.

Multiple (parallel) edges: two or more edges between the same pair of vertices, like the two A–B edges.

A graph with no loops and no multiple edges is called simple. Most algorithms in this unit assume a simple graph.

2.5Connected, components, subgraph

TermMeaning
Connected graphThere is a path between every pair of vertices. You can reach anyone from anyone.
Disconnected graphAt least one pair of vertices has no path between them.
Connected componentA largest connected piece of the graph. A connected graph has exactly one component.
SubgraphA graph made from some of the vertices and some of the edges of G (every edge must join chosen vertices).
Spanning subgraphA subgraph that keeps all vertices of G. A spanning tree is a spanning subgraph that is a tree.
Bridge (cut edge)AdvancedAn edge whose removal increases the number of components.
Cut vertex (articulation point)AdvancedA vertex whose removal (with its edges) increases the number of components.

Why care? In a computer network a bridge is a single cable whose failure splits the network. Network engineers find bridges with a DFS-based algorithm and add backup links.

Example 13 — a loop adds 2

deg(A) = 2, because both parallel edges touch A. deg(B) = 3 (two A–B edges plus B–C). The loop at C counts twice, plus B–C, so deg(C) = 3.

Sum of degrees = 2 + 3 + 3 = 8. Edges = 2 parallel + B–C + 1 loop = 4. And 2 × 4 = 8. The rule still holds.

Exam habit: On any terminology question, draw the graph, label degrees on the vertices, and only then write the definition. One labelled picture is worth more than a paragraph with no example.

Remember from Part 2

  • Degree counts edges at a vertex; a loop adds 2.
  • Path = no repeated vertex. Length = number of edges.
  • Cycle = path that returns to its start.
  • Isolated = degree 0, pendant = degree 1, source = in-degree 0, sink = out-degree 0.
  • Connected = one piece. Each piece of a disconnected graph is a component.
  • Walk may repeat. Trail repeats no edge. Path repeats no vertex. Length = number of edges.
