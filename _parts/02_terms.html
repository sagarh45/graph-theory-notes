Unit V · Part 2

Graph Terminology

Each term is its own section, with one definition and one example. Do not mix them. The picture is the example you can redraw in the exam.

Syllabus: vertex, edge, adjacent vertices and edges, incident, neighbour, degree, in-degree, out-degree, isolated, pendant, source, sink, loop, multiple edges, walk, trail, path, closed walk, circuit, cycle, length, distance, connected, component, subgraph, spanning subgraph, reachable, predecessor, successor, weight, bridge, cut vertex.

2.1Vertex and edge

Definition

A vertex (node) is a point of the graph. An edge (link) joins two vertices. A directed edge is called an arc.

Example. In G, the vertices are A, B, C, D, E, F. One edge is (B, D). Order = |V| = 6. Size = |E| = 8.

2.2Adjacent vertices

Definition

Two vertices are adjacent if one edge joins them directly.

Example. A is adjacent to B and to C. A is not adjacent to D, E or F — you cannot go there in one edge.

2.3Adjacent edges

Definition

Two edges are adjacent if they share a common vertex.

Example. (A, B) and (B, D) are adjacent edges. (A, B) and (E, F) are not — they share no vertex.

2.4Incident

Definition

An edge is incident on the vertices at its two ends. A vertex is incident on every edge that touches it.

Example. Edge (D, F) is incident on D and on F. It is not incident on A.

2.5Neighbour

Definition

The neighbours of v are the vertices adjacent to v.

Example. Neighbours of B = {A, C, D}. Neighbours of F = {D, E}.

2.6Degree

Definition

Degree of v, written deg(v), is the number of edges touching v. A self-loop counts 2. The degree of the graph, Δ(G), is the largest degree.

Example. deg(B) = 3, deg(F) = 1, deg(G) = 0. Sum of degrees = 2+3+3+2+3+1+0 = 14 = 2 × 7 edges.

2.7In-degree

Definition

In a directed graph, in-degree in(v) is the number of arrows that enter v.

Example. in(E) = 2 (from D and F). in(A) = 0. Sum of all in-degrees = number of arrows = 7.

2.8Out-degree

Definition

Out-degree out(v) is the number of arrows that leave v. In a digraph, deg(v) = in(v) + out(v).

Example. out(A) = 2, out(E) = 0. Sum of all out-degrees = 7, the same as the sum of in-degrees.

2.9Isolated vertex

Definition

An isolated vertex has degree 0. No edge touches it.

Example. D is isolated. A, B and C are not.

2.10Pendant vertex

Definition

A pendant vertex (leaf) has degree exactly 1.

Example. A and D are pendant. B and C are not.

2.11Source

Definition

A source is a vertex with in-degree 0. Arrows only leave it.

Example. A is a source. B is not, because the arrow A → B enters B.

2.12Sink

Definition

A sink is a vertex with out-degree 0. Arrows only enter it.

Example. D is a sink. in(D) = 2, out(D) = 0.

2.13Loop (self-loop)

Definition

A loop is an edge from a vertex to itself. In an undirected graph it adds 2 to the degree.

Example. C has a loop and the edge B–C, so deg(C) = 2 + 1 = 3.

2.14Multiple (parallel) edges

Definition

Multiple edges are two or more edges with the same two end vertices. Each one is a separate edge.

Example. There are 3 edges between A and B, so they add 3 to deg(A) and 3 to deg(B).

2.15Walk

Definition

A walk is a sequence of vertices where each next vertex is adjacent to the one before. Vertices and edges may repeat.

Example. A–B–C–A–B–D is a walk from A to D. It repeats A, B and the edge A–B, so it is not a path.

2.16Trail

Definition

A trail is a walk that repeats no edge. A vertex may still repeat.

Example. A–B–D–E–C–B is a trail: no edge is used twice, but B appears twice, so it is not a path.

2.17Path

Definition

A path (simple path) is a walk with no repeated vertex.

Example. A–B–D–F is a path. A–B–C–A–B–D is not, because A and B repeat.

2.18Closed walk

Definition

A closed walk starts and ends at the same vertex. It may repeat vertices and edges.

Example. A–B–C–A is a closed walk of length 3. A–B–D is not closed: it starts at A and ends at D.

2.19Circuit

Definition

A circuit is a closed trail: it returns to the start and repeats no edge.

Example. B–C–E–D–B is a circuit of length 4. A–B–C–A–B–A is a closed walk, not a circuit, because A–B is used twice.

2.20Cycle

Definition

A cycle is a closed path of length at least 3: no vertex repeats except that the first vertex is also the last.

Example. D–E–F–D is a cycle. A loop is not called a cycle here. A cycle of length 3 is a triangle.

2.21Length

Definition

The length of a walk, path or cycle is the number of edges in it, not the number of vertices.

Example. A–B–D–F has 4 vertices and length 3. The cycle D–E–F–D has length 3.

2.22Distance

Definition

The distance from u to v is the length of the shortest path from u to v. If no path exists, the distance is infinite.

Example. Distance from A to F is 3. A–C–E–F is also length 3. No shorter path exists. BFS finds this.

2.23Connected graph

Definition

An undirected graph is connected if there is a path between every pair of vertices.

Example. G is connected. From F you can reach A by F–D–B–A.

2.24Disconnected graph and component

Definition

A graph is disconnected if some pair of vertices has no path between them. A component is one largest connected piece.

Example. This graph has 3 components. F is a component by itself. A connected graph has exactly 1 component.

2.25Subgraph

Definition

A subgraph uses some of the vertices and some of the edges of G. Every chosen edge must join two chosen vertices.

Example. Vertices {D, E, F} with edges D–E, E–F, D–F form a subgraph. It is a triangle.

2.26Spanning subgraph

Definition

A spanning subgraph keeps every vertex of G. A spanning tree is a spanning subgraph that is a tree (n − 1 edges, no cycle).

Example. The thick edges form a spanning tree of G: 6 vertices, 5 edges, no cycle.

2.27Reachable

Definition

In a directed graph, v is reachable from u if a directed path goes from u to v.

Example. C is reachable from A (A → B → C). A is not reachable from C: no arrow leads back. E can reach D, but D cannot reach E.

2.28Predecessor and successor

Definition

If the arrow u → v exists, u is a predecessor of v and v is a successor of u.

Example. Predecessors of C are A and B. Successors of A are B and C. E has no successor in the earlier digraph, so E is a sink.

2.29Weight

Definition

A weight is a number on an edge: distance, cost or time. A graph with weights is a weighted graph.

Example. Weight of A–B is 4. The path A–B–D has total weight 4 + 5 = 9. Length of that path is still 2 (two edges).

2.30Bridge and cut vertex

Definition

A bridge is an edge whose removal increases the number of components. A cut vertex is a vertex whose removal does the same.

Example. Delete C–D and the graph splits. So C–D is a bridge. Delete C and {A, B} is cut off from {D, E}. C is a cut vertex. A–B is not a bridge: A–C–B remains.

Remember from Part 2

  • Adjacent = joined by an edge. Incident = the edge touches that vertex.
  • Degree counts edges. A loop adds 2. Isolated = 0, pendant = 1.
  • Source = in-degree 0. Sink = out-degree 0.
  • Walk may repeat. Trail repeats no edge. Path repeats no vertex. Length = number of edges.
  • Cycle = closed path, length at least 3. Connected = one component.
